# 宿舍补给计划

算清每个日用品的**预计用完日**和**补货日**，把相近的补货合并成一单，凑够京东自营 ¥59 免运费。

手机电脑都能看：https://02959.github.io/supply-plan/

## 页面

| 页面 | 内容 |
|---|---|
| `index.html` | 主页：15 天内快用完的 + 最近一单 |
| `plan.html` | 全部采购计划（可调安全库存、合并窗口） |
| `items.html` | 物品清单（改库存/月耗、打卡、添加品类） |
| `price.html` | 价格浮动（7/30/90 天折线 + 该不该等大促） |
| `cost.html` | 成本概览 + 打卡记录 + 导入导出 |

导航在每页顶部，横向一排。

## 文件分工

| 文件 | 作用 | 谁改 |
|---|---|---|
| `data.js` | **唯一数据源**：品类、规格、价格、消耗、大促日历 | 你随时改，不用碰代码 |
| `app.js` / `style.css` | 程序与样式 | 不用改 |
| `cloud.json` | 你的记录（打卡、改过的库存、自定义品类） | 页面「导出数据」生成 |

`data.js` 用 `<script>` 引入而不是 `fetch`，所以**本地双击也能用**，Pages 也能用，而且只有一份数据。

## 加商品

### ① 网页上直接加

「物品清单」页 →「＋ 添加品类」→ 填品类名、单位、规格、每件总量、单价、库存、月耗。
存在本机，点「导出数据」能带走。

### ② 改 data.js（推荐，手机也能改）

GitHub 网页里点 `data.js` → 铅笔图标 → 在 `items` 数组里照着加一段 → Commit。

```js
{
  "cat": "洗衣凝珠",
  "name": "奥妙 洗衣凝珠 52颗",
  "unit": "颗",
  "stock": 60,
  "rate": 30,
  "rateFast": 35,
  "rateSlow": 26,
  "offers": [
    { "name": "奥妙 洗衣凝珠", "spec": "52颗单盒", "total": 52, "unit": "颗", "price": 29.9 },
    { "name": "奥妙 洗衣凝珠", "spec": "52颗×2盒", "total": 104, "unit": "颗", "price": 49.9 }
  ],
  "hist": []
}
```

必填：`cat`、`unit`、`stock`、`rate`、`offers[].total`、`offers[].price`。
`offers` 放多个规格时，程序会自动按「元/100 单位」挑最划算的。

### ③ 改 CSV 重新生成（批量）

在 `supply/` 里改 `stock.csv`、`offers.csv`、`price_log.csv`，然后 `python build_site2.py`。

## 每日用法

1. 打开主页看「快用完的」和「最近一单」
2. 下单后去「物品清单」点行尾 **🧾**：填件数 + 实付 → 自动加库存、记一笔单位价
3. 只是看到价格变了，点 **＋**：只记价，不动库存
4. 想让别的设备看到你的记录：点「导出数据」→ 把 `cloud.json` 提交到仓库 → 其他设备点「导入数据」

## 口径

- 单位价：价格 ÷ 总规格量 × 100（抽纸看元/100 抽，液体看元/100ml）
- 免运费：京东自营满 ¥59 免基础运费 ¥6（超重另计）
- 价保：家庭清洁/纸品、个人护理、食品饮料 30 天，入口「我的订单 → 服务中心 → 价格保护」
- 大促节点在 `data.js` 的 `milestones` 里，跨年自己补

## 已知限制

- 价格只能手动补录：京东价格接口有签名校验，网页里抓不到
- 手机和电脑的 localStorage 不互通，靠 `cloud.json` 手动同步
