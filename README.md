# 宿舍补给计划

一个单文件网页：算清每个日用品的**预计用完日**和**补货日**，把相近的补货合并成一单，凑够京东自营 ¥59 免运费。

- 纯静态、零依赖，手机电脑都能看
- 日期按**打开当天**实时计算，不是生成时的快照
- 库存、打卡、自定义品类存在浏览器本地（localStorage）
- 价格曲线靠手动补录，攒够点才判断「该不该等大促」

## 三个文件的分工

| 文件 | 作用 | 谁改 |
|---|---|---|
| `index.html` | 程序（界面 + 计算 + 图表） | 不用改 |
| `data.json` | **数据**：品类、规格、价格、消耗、大促日历 | 你随时改，不用碰代码 |
| `cloud.json` | 你的记录：打卡历史、改过的库存、自定义品类 | 页面「导出数据」生成，替换提交 |

页面打开时会先读 `data.json`，再读 `cloud.json`（本地已有记录时不覆盖）。

## 加商品：三种方式，都不用改代码

### ① 网页上直接加（最快）

物品清单上方 →「＋ 添加品类」→ 填品类名、单位、规格、每件总量、单价、库存、月耗。
存在本机，点「导出数据」就能带走。

### ② 改 data.json（推荐，手机也能改）

GitHub 网页里点 `data.json` → 铅笔图标 → 在 `items` 数组里照着加一段 → Commit。
刷新页面就生效，所有设备都看到。

```json
{
  "cat": "洗衣凝珠",
  "name": "奥妙 洗衣凝珠 52颗",
  "unit": "颗",
  "stock": 60,
  "rate": 30,
  "rateFast": 35,
  "rateSlow": 26,
  "offers": [
    { "spec": "52颗单盒", "total": 52, "price": 29.9 },
    { "spec": "52颗×2盒", "total": 104, "price": 49.9 }
  ],
  "hist": []
}
```

必填：`cat`、`unit`、`stock`、`rate`、`offers[].total`、`offers[].price`。
`offers` 可以放多个规格，程序会自动按「元/100单位」挑最划算的。

### ③ 改 CSV 重新生成（批量）

在 `supply/` 里改 `stock.csv`、`offers.csv`、`price_log.csv`，然后跑：

```bash
python build_site.py
```

会同时生成新的 `补给计划.html` 和 `data.json`。

## 每日用法

1. 打开网页，看顶部「快用完的」和「最近一单」
2. 下单后点行尾 **🧾**：填件数 + 实付总价 → 自动加库存、记一笔单位价
3. 价格有变化时点 **＋**：只记价，不减库存
4. 想让手机也看到最新状态：点「导出数据」→ 把 `cloud.json` 提交到仓库

## 部署

GitHub → Settings → Pages → Source 选 `main` / `root`，几分钟后得到网址。

## 口径

- 单位价：价格 ÷ 总规格量 × 100（抽纸看元/100 抽，液体看元/100ml）
- 免运费：京东自营满 ¥59 免基础运费 ¥6（超重另计）
- 价保：家庭清洁/纸品、个人护理、食品饮料 30 天，入口「我的订单 → 服务中心 → 价格保护」
- 大促节点在 `data.json` 的 `milestones` 里，跨年自己补

## 已知限制

- 价格只能手动补录：京东价格接口有签名校验，网页里抓不到，抓了也会因改版失效
- 手机和电脑的 localStorage 不互通，靠 `cloud.json` 同步
