# 宿舍补给计划

一个单文件网页：算清每个日用品的**预计用完日**、**补货日**，并把相近的补货合并成一单，凑够京东自营 ¥59 免运费。

- 纯静态，零依赖，手机电脑都能看
- 日期按**打开当天**实时计算，不是生成时的快照
- 库存、打卡记录存在浏览器本地（localStorage）
- 价格曲线靠手动补录，攒够点才判断「该不该等大促」

## 数据怎么更新

1. 在网页上买完点行尾的 **🧾**：填件数和实付总价 → 自动加库存、记一笔单位价
2. 点 **导出数据（cloud.json）** → 浏览器会下载一个 `cloud.json`
3. 把这个文件放到本仓库根目录，替换旧的，提交推送
4. 其他设备打开网页时，本地若还没有记录，会自动采纳这份云端基准

## 部署

GitHub → Settings → Pages → Source 选 `main` / `root`，几分钟后得到网址。

## 口径

- 单位价：价格 ÷ 总规格量 × 100（抽纸看元/100 抽，液体看元/100ml）
- 免运费：京东自营满 ¥59 免基础运费 ¥6
- 价保：家庭清洁/纸品、个人护理、食品饮料 30 天，入口「我的订单 → 服务中心 → 价格保护」
- 大促节点：双 12、年货节、38 节、618、双 11

## 提醒

价格数据需要手动补录——京东价格接口有签名校验，网页里抓不到。这是有意为之：能抓就会有不稳定，记一笔 20 秒，换来可解释的判断。
